# TeenTrack Frontend 🚀

Modern, responsive frontend application for the TeenTrack Smart Teen Expense Tracker.

## ✨ Features

- **📊 Dashboard**: Real-time spending progress, monthly pocket money tracking, and category breakdown.
- **💸 Expense Management**: Add, view, filter, and delete expenses with payment methods.
- **🎯 Budgets**: Monthly category budget management with visual progress indicators.
- **📈 Analytics**: Charts for spending trends, budget vs actuals, and category distributions.
- **💡 Smart Insights**: Contextual tips and spending recommendations.
- **🎨 Glassmorphism & Dark Mode**: Sleek dark and light theme toggle with smooth animations.

## 🛠️ Tech Stack

- **React 18**
- **Vite**
- **Tailwind CSS**
- **Lucide Icons**
- **Recharts**
- **Axios**
- **Supabase Client**

## 🚀 Setup & Running

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

The app will be available at `http://localhost:5173`.
